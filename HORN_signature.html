安裝到 Outlook

方法一：複製貼上（新版 Outlook／網頁版／傳統版都適用）

  1. 左邊填好資料，按「複製簽章」。
  2. Outlook 開啟「設定 → 帳戶 → 簽章」（傳統版：檔案 → 選項 → 郵件 → 簽章）。
  3. 新增一個簽章，在編輯框按 Ctrl + V 貼上，儲存。
  4. 寄一封信給自己，確認 logo 和排版正常。

方法二：簽章檔（傳統版 Outlook，格式最完整）

  1. 按「複製 HTML 原始碼」。
  2. 打開記事本貼上，另存新檔，檔名例如 HORN.htm，編碼選 UTF-8。
  3. 在檔案總管網址列輸入 %APPDATA%\Microsoft\Signatures，把檔案放進去。
  4. 重開 Outlook，在簽章清單選擇 HORN。
